# Task Completion Checklist

Before finalizing any change, ensure the following:

1.  **Visual Consistency**: Check if the changes match the existing design and don't break the layout on mobile/desktop.
2.  **Browser Testing**: Verify in Chrome, Firefox, and Safari if possible.
3.  **Performance**: Ensure no large unoptimized images are added.
4.  **SEO Check**: If modifying content, ensure meta tags and structured data are still correct.
5.  **Git Status**: Run `git status` to see what files were changed.
6.  **Test the Server**: Run `.\start-server.bat` and verify the landing page locally.
