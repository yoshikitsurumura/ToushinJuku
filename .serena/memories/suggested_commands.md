# Suggested Commands

## Local Development
- **Start Local Server**:
    ```powershell
    python -m http.server 8000
    ```
    Alternatively, run the batch script:
    ```powershell
    .\start-server.bat
    ```

## Git Operations
- **Push Changes to GitHub**:
    ```powershell
    python push_git.py
    ```
    Or use the batch script:
    ```powershell
    .\push.bat
    ```

## Image Management
- **Download Placeholder Images**:
    ```powershell
    python download_images.py
    ```

## System Utilities (Windows)
- **List Files**: `ls` or `dir`
- **Search Content**: `grep` (if available) or `findstr`
- **File Content**: `type <filename>` (or use `read_file` tool)
