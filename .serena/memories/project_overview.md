# Project Overview: ToushinJuku_LP

## Purpose
A landing page for "Toushin Juku" (燈心塾), an online-specialized private school based in Akita. It features AI-driven personalized learning and 1-on-1 coaching.

## Tech Stack
- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Frameworks/Libraries**: 
    - Bootstrap 5.3.3 (Responsive grid and components)
    - AOS.js (Scroll animations)
    - Particles.js (Background effects)
- **Utilities**: Python-based scripts for deployment and image management.

## Key Features
- Responsive design (Mobile, Tablet, Desktop)
- AI Chatbot (Akari-chan) integration (Work in progress)
- Smooth scroll animations
- SEO optimization (Meta tags, structured data, sitemap)
